# 深空推进器联锁约束 · DRAT 逐步复核台

上线前把互斥阀位、点火许可、故障隔离等布尔约束编译为受限 DIMACS CNF，
审查员对供应商提交的顺序 DRAT 证明**逐步复核**，而不是只接受“无解”结论。

## 复核规则（均以随步骤变化的活动子句集为依据）

- **RUP**：反设新增子句全部文字为假，在当前活动集上做单位传播，必须导出冲突；
  页面展示冲突子句编号链与链上传播序列。
- **RAT**：RUP 不成立时，以新子句**首文字为指定枢轴**，活动集中每个含枢轴否定
  的子句都必须与新子句消解为重言式，或消解式在当前集上满足 RUP；页面逐一展示
  全部反向文字子句的核对结果（含“零个反向子句 → 空成立”）。
- **删除**：`d ... 0` 立即从活动集移除目标；无活动匹配即判“无目标删除”失败，
  已删除子句不得作为后续依据（删除后传播器失效重建）。
- **终局**：空子句只允许作为最后一条记录；只有活动集确实得到空子句才裁决
  **UNSAT**；各步成立但无空矛盾裁决 INCOMPLETE；任一步失败给出首个失败步骤、
  失败码与当时活动约束摘要。

## 受限语法（问题一次性合并定位）

变量为正整数（文字可带负号），子句/记录以 `0` 结束；同条目中的重复文字、
互补文字、越界变量、截断条目、结束符后多余记号、无目标删除都会被收集并带
行/列位置报告；存在语法问题时不回放、不输出任何旧结论。

## 本地运行

```bash
npm install        # 无运行时依赖，仅为满足工程约定
npm test           # node:test 单元测试（17 项）
npm run build      # 语法检查并装配 dist/
npm start          # http://localhost:8080  （健康路径 /healthz）
npm run smoke      # 对运行中站点打 HTTP 冒烟
npm run verify     # 测试 → 生产构建 → HTTP 冒烟，失败以非零码退出
```

长回放在浏览器 Web Worker 中执行，按步让出事件循环并汇报进度，页面保持可操作；
支持“中止回放”与“清空草稿与结论”。

## Docker Compose

```bash
docker compose up --build web       # 启动站点（含 /healthz 健康检查）
docker compose run --build verify   # 一次性验收服务
```

`verify` 服务等待 `web` 健康后，在容器内依次执行 **代码测试 → 生产构建 →
关联五个证明场景的 HTTP 冒烟（RUP 冲突链、无反向文字子句的 RAT、删除后空矛盾
失败、混合非法输入、重复删除）**，全部通过自行退出 0，否则退出 1。
